# asnimansari.dev

Personal site built with [Zola](https://www.getzola.org/) and the [serene](https://github.com/isunjn/serene) theme (git submodule at `themes/serene`).

## Blog post writing style

- Never use em dashes (`—`) in post content. Use a period, comma, or colon instead. Em dashes are a strong tell of AI-written text, and posts on this site should read like they weren't generated.
- This applies to prose in `content/posts/**/*.md`. Code comments and code blocks are exempt.
